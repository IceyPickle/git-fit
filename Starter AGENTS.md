# Agent Instructions

- Read existing documentation and repository instructions before making changes.
- Respect the requested scope. Preserve unrelated changes and do not overwrite user work.
- When diagnosing, identify the cause before implementing a fix. Do not implement until requested.
- Prefer small, reviewable diffs. Run relevant checks and report failures accurately.
- Never commit secrets, credentials, tokens, or confidential work information.
- Use personal GitHub only through approved personal repository connections.
- Never use work connectors, APIs, or remote GitHub integrations for Volkert or Debris Optics tenants or the debris-optics organization.
- For work tasks, access only the explicitly opened, authorized browser, VS Code, or GitHub Desktop session, when requested and permitted by company policy.
- Do not infer permission from an open application. Stop if authorization is unclear.
- Ask before pushing, opening pull requests, deleting data, publishing, or taking other consequential actions.
- If blocked, identify the problem, attempt safe in-scope recovery, and notify the user with the status and next step. Do not silently stall.
